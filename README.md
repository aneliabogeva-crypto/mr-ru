# Mr.Ru – калкулатор за ремонти и платформа за майстори

Уеб приложение на React (Vite), което свързва клиенти, търсещи ремонт, с майстори.

- **Клиент:** калкулатор по пазарни средни цени, сравнение на майстори, Viber/WhatsApp, запитвания и FAQ чатбот.
- **Майстор:** ценоразпис с „Не се предлага“, входящи запитвания, конструктор на оферти, PDF, имейл, Viber и WhatsApp.

Това е **MVP без бекенд**: данните (майстори, запитвания, ценоразписи) се пазят в `localStorage` на браузъра. Майсторите и цените в `src/data/seed.js` са примерни.

## Стартиране

Нужен е Node.js 18 или по-нов.

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # продукционна версия в dist/
npm run preview   # преглед на dist/
```

## Как работят основните неща

**Пазарни средни цени.** `computeMarket()` взима цените на всички майстори, които предлагат дадена услуга, и смята средна, минимална и максимална стойност. Промяна в ценоразписа на майстор веднага променя средните цени в калкулатора.

**„Не се предлага“.** Услуга, маркирана така, се показва на клиента като „По договаряне“. В офертата такава позиция няма цена и не влиза в общата сума, докато майсторът не впише цена.

**PDF.** `lib/pdf.js` използва jsPDF с вграден шрифт DejaVu Sans, защото стандартните шрифтове на jsPDF нямат кирилица. Модулът се зарежда динамично при натискане на „Изтегли PDF“.

**Viber, WhatsApp, имейл.** Използват се дълбоки връзки (`viber://`, `https://wa.me/`, `mailto:`). Те пренасят само текст, затова PDF файлът се прикачва ръчно. Автоматично изпращане на PDF по имейл изисква бекенд (виж по-долу).

**Езици.** Текстовете са в `src/i18n/bg.js` и `en.js`; превключвател BG/EN има в горния десен ъгъл. Нов текст: добавете ключ и в двата файла и използвайте `t("ключ")`.

**Чатбот.** Отговаря по правила: въпроси за цена на конкретна услуга получават актуалната средна цена, останалите се търсят в `data/faq.js`. За LLM отговори добавете бекенд ендпойнт и го извикайте в `Chatbot.jsx`, когато `answer()` върне `null`. Не слагайте API ключ във фронтенда.

## Следващи стъпки (бекенд)

1. API и база данни за майстори, ценоразписи, запитвания и оферти (замества `usePersistentState`).
2. Регистрация и вход с роли Клиент / Майстор (замества избора на профил в режим „Майстор“).
3. Изпращане на PDF по имейл от сървъра (SMTP или услуга като SendGrid, Postmark).
4. Отзиви и рейтинг, филтър по локация, календар за огледи.
5. Мобилни приложения: React Native или обвивка (Capacitor) върху същия код за Google Play и App Store.
