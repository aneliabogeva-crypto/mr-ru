# Mr.Ru – калкулатор за ремонти и платформа за майстори

Уеб приложение на React (Vite), което свързва клиенти, търсещи ремонт, с майстори.

- **Клиент:** калкулатор по пазарни средни цени, сравнение на майстори, Viber/WhatsApp, запитвания и FAQ чатбот.
- **Майстор:** ценоразпис с „Не се предлага“, входящи запитвания, конструктор на оферти, PDF, имейл, Viber и WhatsApp.

Данните (майстори, ценоразписи, запитвания) са в **Supabase** (PostgreSQL, регион ЕС). Майсторите влизат с имейл и парола. Профилите с `is_demo = true` са примерни и служат за начални пазарни цени.

## Стартиране

Нужен е Node.js 18 или по-нов.

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # продукционна версия в dist/
npm run preview   # преглед на dist/
```

## Публикуване

Сайтът се публикува автоматично в GitHub Pages при всеки push в `main`

## База данни (Supabase)

- **Схема и правила за достъп:** `supabase/schema.sql`. Пуска се в Supabase → SQL Editor. Може да се пусне повторно.
- **Кой какво вижда:**
  - всеки вижда профилите и ценоразписите на майсторите;
  - всеки може да изпрати запитване, но не може да чете запитвания;
  - майсторът вижда и сменя статуса само на своите запитвания и редактира само своя профил;
  - собственикът на проекта вижда всичко в Supabase → Table Editor.
- **Ключове:** адресът и публичният (publishable) ключ са в `src/lib/supabase.js`. Те не са тайна. Никога не слагайте `service_role` или secret ключ във фронтенда.
- **Вход:** в Authentication → URL Configuration трябва Site URL да е адресът на сайта, иначе линковете в имейлите водят на грешно място.
- **Демо майстори:** `delete from public.contractors where is_demo;` ги премахва.

## Пазарни цени

- **Референтни цени:** `src/data/marketReference.js` съдържа обявени цени за труд от публични ценоразписи (с източник и дата). Референтната цена е **медианата** на точките, а не средно аритметично.
- **Пазарна цена в приложението:** медианата от референтната цена и цените на всички майстори, които предлагат услугата. Типичният диапазон е от 25-ия до 75-ия перцентил (`src/lib/market.js`).
- **Обновяване:** добавете нови точки в `marketReference.js`, после генерирайте SQL за демо майсторите (виж `supabase/2026-10-09-market-prices.sql`).

## Готови помещения

`src/lib/rooms/bathroom.js` описва банята: размери, опции за таван, стени, под, ВиК, електро и врата. От тях изчислява количествата по услуги от каталога. Другите помещения (кухня, спалня, хол, коридор) ще се добавят по същия модел.

## Как работят основните неща

**Пазарни средни цени.** `computeMarket()` взима цените на всички майстори, които предлагат дадена услуга, и смята средна, минимална и максимална стойност. Промяна в ценоразписа на майстор веднага променя средните цени в калкулатора.

**„Не се предлага“.** Услуга, маркирана така, се показва на клиента като „По договаряне“. В офертата такава позиция няма цена и не влиза в общата сума, докато майсторът не впише цена.

**PDF.** `lib/pdf.js` използва jsPDF с вграден шрифт DejaVu Sans, защото стандартните шрифтове на jsPDF нямат кирилица. Модулът се зарежда динамично при натискане на „Изтегли PDF“.

**Viber, WhatsApp, имейл.** Използват се дълбоки връзки (`viber://`, `https://wa.me/`, `mailto:`). Те пренасят само текст, затова PDF файлът се прикачва ръчно. Автоматично изпращане на PDF по имейл изисква бекенд (виж по-долу).

**Езици.** Текстовете са в `src/i18n/bg.js` и `en.js`; превключвател BG/EN има в горния десен ъгъл. Нов текст: добавете ключ и в двата файла и използвайте `t("ключ")`.

**Чатбот.** Отговаря по правила: въпроси за цена на конкретна услуга получават актуалната средна цена, останалите се търсят в `data/faq.js`. За LLM отговори добавете бекенд ендпойнт и го извикайте в `Chatbot.jsx`, когато `answer()` върне `null`. Не слагайте API ключ във фронтенда.

## Следващи стъпки (бекенд)

1. Собствен SMTP в Supabase (вграденият изпраща ограничен брой имейли), имейл известие до майстора при ново запитване.
2. Администраторски екран и защита от спам при запитванията (напр. CAPTCHA).
3. Изпращане на PDF по имейл от сървъра (SMTP или услуга като SendGrid, Postmark).
4. Отзиви и рейтинг, филтър по локация, календар за огледи.
5. Мобилни приложения: React Native или обвивка (Capacitor) върху същия код за Google Play и App Store.
